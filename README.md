# [Silat Cekak pose correctness classification using computer vision]

Silat Cekak practitioner difficult to determine their pose correct or not when practise alone. 

## Problem statement
Beginner and intermediate Silat Cekak practitioner need to practise their technique so that it be easier if they go to next level. practise independently makes it tough to know if the technique is executing properly without a qualified instructor watching over. Minor errors in basic body positioning like misaligned joints can easily turn into bad habits and ultimately ruin the effectiveness of the training.
